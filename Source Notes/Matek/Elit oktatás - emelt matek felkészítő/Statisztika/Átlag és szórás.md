# STATISZTIKAI MUTATÓK (SZÁMÍTÁSOK)

Legyen $X = \{x_1, x_2, \dots, x_n\}$ egy adathalmaz (minta), ahol $n$ az elemek száma.

---

- **Átlag ($\bar{x}$):**
  $$\bar{x} = \frac{x_1 + x_2 + \dots + x_n}{n}$$

- **Átlagos abszolút eltérés:**
  $$\frac{|\bar{x} - x_1| + |\bar{x} - x_2| + \dots + |\bar{x} - x_n|}{n}$$

- **Szórás ($\sigma$):**
  $$\sqrt{\frac{(\bar{x} - x_1)^2 + (\bar{x} - x_2)^2 + \dots + (\bar{x} - x_n)^2}{n}}$$
