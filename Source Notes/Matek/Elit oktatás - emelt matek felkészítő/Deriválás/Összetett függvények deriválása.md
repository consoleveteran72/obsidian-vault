
**1. Példa:**

$$\left[(8x+10)^6\right]' = 6 \cdot (8x+10)^5 \cdot 8$$

* **Külső függvény:** $f(x) = x^6$
* **Belső függvény:** $g(x) = 8x + 10$
* *(megjegyzés: $8 = (8x+10)'$)*

---

**2. Példa:**

$$\left[\text{tg}\left(2x + \frac{\pi}{2}\right)\right]' = \frac{1}{\cos^2\left(2x + \frac{\pi}{2}\right)} \cdot 2$$

* **Külső függvény:** $f(x) = \text{tg } x$
* **Belső függvény:** $g(x) = 2x + \frac{\pi}{2}$
* *(megjegyzés: $\left(2x + \frac{\pi}{2}\right)' = 2$, mivel $\frac{\pi}{2}$ konstans)*

# DERIVÁLHATÓSÁG SZEMLÉLETES JELENTÉSE

**Pangyolán:** $f(x)$ deriválható $x_0$-ban, ha ott $f$ „sima” *(nem böki a tenyerünket)*.

**Példa – Szignum (előjel) függvény:**

$$\text{sgn}(x) = \begin{cases} 1 & \text{ha } x > 0 \\ 0 & \text{ha } x = 0 \\ -1 & \text{ha } x < 0 \end{cases}$$

* A $\text{sgn}(x)$ függvény **NEM folytonos** $0$-ban $\implies$ **NEM deriválható** $0$-ban.
