**Def.:** Az $ABCD$ négyszög érintőnégyszög, ha van olyan kör, aminek a négyszög mind a 4 oldala érintője.

**Tétel:** Egy $ABCD$ négyszög pontosan akkor érintőnégyszög, ha szemközti oldalainak összege egyenlő.

**Biz.:**

$$\text{kell: } a + c = b + d$$

Legyenek $E, F, G, H$ az érintési pontok. Ekkor:

$$DH = DG = x \quad \text{mert } D\text{-ből húzott érintőszakaszok.}$$

Hasonlóan:

$$CG = CF = y$$

$$BF = BE = z$$

$$AE = AH = u$$

$$a + c = u + z + x + y = b + d$$
