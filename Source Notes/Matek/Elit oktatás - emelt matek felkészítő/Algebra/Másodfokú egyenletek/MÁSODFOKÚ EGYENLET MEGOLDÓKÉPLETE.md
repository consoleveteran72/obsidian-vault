MÁSODFOKÚ EGYENLET MEGOLDÓKÉPLETE (ÁLTALÁNOS TELJES NÉGYZETTÉ ALAKÍTÁS)

$$ax^2 + bx + c = 0 \quad (a \neq 0, \, a, b, c \in \mathbb{R})$$

---

## Teljes négyzetté alakítás lépései

1. Kiemelünk $a$-t az első két tagból:
   $$a \left(x^2 + \frac{b}{a} x\right) + c = 0$$

2. Teljes négyzetté alakítás a zárójelen belül:
   $$a \left[\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2}\right] + c = 0$$

3. Felbontjuk a külső zárójelet:
   $$a \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a} + c = 0$$

4. Átrendezzük a konstans tagokat a jobb oldalra:
   $$a \left(x + \frac{b}{2a}\right)^2 = \frac{b^2}{4a} - c$$

5. Közös nevezőre hozzuk a jobb oldalt:
   $$a \left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a} \quad / : a$$

6. Osztunk $a$-val:
   $$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2} \quad / \sqrt{\phantom{x}}$$

7. Gyökvonást végzünk mindkét oldalon:
   $$x + \frac{b}{2a} = \frac{\pm \sqrt{b^2 - 4ac}}{2a}$$

---

## Megoldóképlet
$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
