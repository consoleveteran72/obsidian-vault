
$$ax^2 + bx + c$$

---

## I. CASE: $a > 0$ (felfelé nyitott parabola)

### 1. Két megoldás / zérushely ($D > 0$)
- $ax^2 + bx + c > 0 \implies x < x_1 \text{ v. } x > x_2$
- $ax^2 + bx + c \ge 0 \implies x \le x_1 \text{ v. } x \ge x_2$
- $ax^2 + bx + c < 0 \implies x_1 < x < x_2$
- $ax^2 + bx + c \le 0 \implies x_1 \le x \le x_2$

### 2. Egy megoldás / zérushely ($D = 0$)
- $ax^2 + bx + c > 0 \implies x \in \mathbb{R} \setminus \{x_{1,2}\}$
- $ax^2 + bx + c \ge 0 \implies x \in \mathbb{R}$
- $ax^2 + bx + c < 0 \implies \text{nincs megoldás}$
- $ax^2 + bx + c \le 0 \implies x = x_{1,2}$

### 3. Nulla megoldás / zérushely ($D < 0$)
- $ax^2 + bx + c > 0 \implies x \in \mathbb{R}$
- $ax^2 + bx + c \ge 0 \implies x \in \mathbb{R}$
- $ax^2 + bx + c < 0 \implies \text{nincs m.o.}$
- $ax^2 + bx + c \le 0 \implies \text{nincs m.o.}$

### 3. Nulla megoldás / zérushely ($D < 0$)
