**2. NEM folytonos, de VAN határérték**

$$f(x) = \begin{cases} x, & \text{ha } x \neq 1 \\ 2, & \text{ha } x = 1 \end{cases}$$

---

**3. NEM folytonos, de VAN határérték**

$$f(x) = \frac{x^2 - 1}{x - 1}$$

---

**4. NINCS határérték (ugrás)**

$$\text{sgn } x = \begin{cases} -1, & \text{ha } x < 0 \\ 0, & \text{ha } x = 0 \\ 1, & \text{ha } 0 < x \end{cases}$$

---

**5. Dirichlet-függvény**

$$f(x) = \begin{cases} 1, & \text{ha } x \in \mathbb{Q} \\ 0, & \text{ha } x \notin \mathbb{Q} \end{cases}$$
